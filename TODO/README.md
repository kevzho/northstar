# TODO — review and submission tracker

Working checklists for finishing the Congressional App Challenge submission.
Claude appends to these as features land; Kevin checks items off as he
verifies them by hand. Nothing here is done until the box is checked.

- [code-review.md](code-review.md) — every file to read, prioritized by
  "a judge might ask about this," with what to verify in each.
- [submission.md](submission.md) — the remaining CAC deliverables
  (smoke test, video, disclosure) and operational tasks.

Convention: when a new feature is added, its review items get appended to
code-review.md under "Recently added" with the commit hash, then get sorted
into tiers once reviewed.
